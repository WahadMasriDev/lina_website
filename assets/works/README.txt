WORKS IMAGES — drop your real project images here
==================================================

The homepage already looks finished WITHOUT these files: each work card
shows a hand-made "liquid chrome" gradient until you add a real image.
As soon as a file with the matching name exists here, it replaces the
gradient automatically (no code change needed).

Add these exact filenames (JPG or PNG, same name):

  disturbia.jpg       -> "Disturbia" card        (3D abstract concept art)
  equilibrium.jpg     -> "Equilibrium" card      (3D abstract concept art)
  outcast.jpg         -> "Outcast" card          (typography / editorial)
  portfolio-2024.jpg  -> "Graphic Design Portfolio" card
  og-cover.jpg        -> social-share preview image (1200 x 630 px)

Recommended sizes
-----------------
  Cards        : ~1600 px on the long edge, < 400 KB each (JPG quality ~80).
  og-cover.jpg : exactly 1200 x 630 px.

Where to get them
-----------------
Export from your own Behance project:
  https://www.behance.net/gallery/190862649/Graphic-design-PORTFOLIO-2024-Lina-Zakaria
Only use images you own / are allowed to publish.

Tip: keep the names lowercase with no spaces, exactly as listed above.
